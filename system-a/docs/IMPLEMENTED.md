# System A 2.0 实现范围

## 创作与采用

- 原创选题、故事结构、场景、剧本正文和局部精修均使用候选→复核→采用，不直接覆盖正式稿。
- 小说 TXT/粘贴入口先完成全书分段分析，再逐段改编；保存原文版本、内容指纹、稳定定位、分析覆盖和实际阅读范围。
- 全书分析包含主线、人物关系、时间线、伏笔、关键物件、世界规则、保护事实、改编机会和待核实问题；原文更新按内容指纹复用未变化单元。
- 事实、人物知识/误信、观众知识、事件状态和戏剧作用分别保存。被拒绝候选不会进入正式事实。
- `/advance` 提供单步兼容和自动推进到下一选择点；后台任务支持请求去重、取消、恢复及依据变化保护。

## 版本、经验与交付

- 节点修订、分支、锁定、恢复、结构操作、影响预览、连续性检查、语义扫描和阅读导出。
- 明确反馈、本作品经验、待确认推测偏好、同类/全局推广、效果验证、停用与撤销。
- `ExperiencePack-v1` 可导入/导出；生效经验及规则版本进入生成、审查和缓存依据。
- 本地 Codex CLI 按创作、小说分析和独立审查复用职责会话，增量同步变化和适用经验。
- SceneExport v4 导出来源、分析覆盖、稳定正文/对白 ID、事件、状态、知识、戏剧作用、证据快照和版本指纹；继续保留通用 JSON、Fountain、FDX、HTML 与项目备份。

## 边界

演示模式只验证结构、状态和交互，不代表真实剧本质量。知识检查只裁决已声明的事实与证据，不从任意台词假定全知。正式图片与视频制作交给 System B。
