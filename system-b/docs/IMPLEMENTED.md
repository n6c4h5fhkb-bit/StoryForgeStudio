# System B 2.0 实现范围

## 呈现转换与导演

- 读取 SceneExport v1–v4；v4 保留分析覆盖、知识、戏剧作用与证据。
- 电影、剧集、快节奏短剧拍摄版分别保存。采用前预览改变、保留和下游影响；导入新版 A 稿不覆盖已采用分支。
- 受保护故事事实、来源映射、播放顺序、预演/倒叙/跳时和对白覆盖检查。
- 关键场次提供差异拍法；普通场次自动采用独立复核后的推荐稿。分镜与生成单元分离。

## 素材、连续性与媒体

- 拍摄稿提取→粗分镜筛选→正式分镜反查；稳定身份主图与临时状态变体分开。
- 事件账本覆盖开合、损坏、换装、伤势、位置、持有、包含、隐藏、未知、空和销毁。
- 参考图保存控制范围、排除继承、状态、文件哈希和观察依据，并进入 Prompt 和缓存键。
- Dreamina CLI、OpenAI 图片、Generic HTTP、ComfyUI、手工导入及本地演示 Provider。
- Dreamina 使用当前 CLI 帮助校验 Seedance 模型能力；保存 `submit_id` 并支持查询恢复，无可靠 ID 时禁止盲目重提。
- 视频真实时间点抽帧、独立对白听检状态、人工审片、采用区间、首尾帧哈希、实际末态和强依赖传播。

## 经验、会话与导出

- 反馈可绑定场次、镜头、选中文字或时间点；范围、例外、应用、有效/复发/误用/未知和撤销均持久化。
- 本地 Codex CLI 按呈现方向、场次导演和独立审查复用会话，只同步变化与适用经验。
- 每批生成先 dry-run，显示任务、参考、缓存和已知费用；付费媒体不自动重试。
- 独立制作包包含采用媒体原文件、采用区间、镜头顺序、对白/声音提示、素材对应、参考职责、来源映射、版本清单、HTML 与机器清单。
- 旧 B6 装配器保留兼容和粗剪；主流程在外部软件完成配音、字幕和最终剪辑。

## 边界

没有专用检测器或真实 VLM 时，身份、手脸、文字和时序判断保持 `unknown`，不能伪装通过。演示素材不代表 Seedance 成片质量；真实媒体仍须逐批付费确认和人工终选。
