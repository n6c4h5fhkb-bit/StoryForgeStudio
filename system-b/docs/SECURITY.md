# 安全与费用边界

应用仅监听回环地址。写操作有本地请求头和 Origin 检查，文件读取只允许已注册媒体，上传有扩展名和体积限制，备份恢复不执行 ZIP 内容，SQLite 操作日志不可更新/删除。

模型密钥保存在本机 settings.json，界面返回占位符。模型/Agent 提交给第三方服务的文本和图像不再只存在本机。审计保存上下文，包含你的创作私有数据；导出项目备份前应自行确认分享范围。

预算检查基于你确认的单价、token 预估和实际回执。超时/断网后服务商可能已经计费，程序保守计入预留值并标记费用待核实。用户更换单价、供应商额外收费或服务商计价误差不能被本地程序完全控制，务必同时设置服务商账户预算上限。

取消请求不会保证已提交到服务商的远端任务取消。服务重启将本地未完成任务标为 interrupted，不会偷偷重启付费任务。恢复项目不恢复有效缓存，运行缓存依赖原始文件内容 hash。

System B 的内建 subprocess 是随软件交付的可信渲染脚本，不是可运行任意 shell 的 Agent。第三方 Runner 必须通过当前配置对应的 12 项验收；默认进入 Docker 限写 /work 的环境，也可显式选择本机直连（`sandbox.type='host'`），后者以你的用户权限运行、没有操作系统级沙箱，只在你信任该 CLI 时使用。工作目录约定不是沙箱。不要把系统文件、SSH 密钥或整个家目录挂载给 Runner；不要关闭沙箱以绕过验收失败。

默认路由为 subprocess，没有后台自动切换 Agent；Codex/Pi 的安装、密钥、镜像和能力测试由本机设置决定。相同 renderKey 命中缓存时不启动任何 Runner。
