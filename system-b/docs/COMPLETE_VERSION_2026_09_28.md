# A/B 2.0 完整版本说明

## 已完成的主流程

```text
System A
├─ 原创：选题候选 → 故事结构 → 场景 → 剧本 → 采用稿
└─ 小说：TXT/粘贴 → 全书分段理解与缓存 → 分段改编 → 采用稿
   ↓ SceneExport-v1 / schemaVersion 4
System B
├─ 呈现转换：电影 / 剧集 / 快节奏短剧（版本互不覆盖）
├─ 关键拍法：开场、亮相、反转、高潮、复杂调度提供差异方案
├─ 正式分镜：普通场次自动采用独立复核后的推荐稿
├─ 素材：拍摄稿提取 → 粗分镜筛选 → 正式分镜反查
├─ 生成：参考职责核对 → 费用预览 → 图片/视频 → 真实文件审查
└─ 采用与导出：采用区间、实际末态、连续依赖 → 独立制作包
```

用户主要阅读作品、比较完整候选、采用结果和输入自然语言修改意见。程序自动处理结构、状态、引用、缓存、影响传播和恢复；模型负责创作、因果、导演判断和独立审查。写操作使用请求去重及依据版本校验。

## A：原创与小说改编

- 小说入口支持 TXT 和粘贴正文，保存文件名、原文 SHA-256、稳定章节/分段定位、来源版本和实际阅读范围。
- “载入原文”“完成语义分析”“用于本次改编”分别记录。只有完成全书分段分析后才开始改编。
- 全书分析保存主线、人物关系、时间线、伏笔、关键物件、世界规则、保护事实、改编机会及待核实项。
- 分段分析按内容指纹复用。更新原文后只分析变化单元，再重建受影响的全书结论；取消和重启可恢复。
- 候选、拒绝稿和采用稿分开。被拒绝内容不会进入正式事实；事实、人物知识/误信、观众知识和戏剧作用单独保存。
- `/advance` 支持 `single` 与 `until_choice`。界面默认只读取本轮所选章节并停在首个改编候选；全书深读作为独立后台任务，逐单元保存并复用结果。

## B：二次影视化、导演与连续性

- 同一份 A 剧本可分别产生电影、剧集和快节奏短剧拍摄版。局部修改保留未变化场次；导入新版 A 文件先计算差异，不覆盖已经采用的 B 分支。
- 转换允许压缩对白、外化心理、合并场次和调整观看顺序。人物身份、关键动机、世界规则及重大因果结果受保护；越界变化进入故事修改提案。
- 分镜、对白覆盖、素材和生成只读取当前采用的 B 拍摄版，并保留 A 正文块到 B 场次/对白/镜头的映射。
- 事件状态覆盖开合、损坏、服装、伤势、位置、持有和包含关系；未知、隐藏、空与销毁分别表达。
- 故事顺序与播放顺序分开；预演、倒叙、跳时显式记录，并重新验证人物与观众的知情顺序。
- 调度保存空间锚点、人物/物件位置、摄影机侧和屏幕方向。人物自身左右与画面左右分开；越轴必须声明导演意图。

## 素材、Dreamina 与真实审片

- 稳定身份主图与临时状态变体分开。每项参考图记录“控制什么”“不继承什么”、适用状态、真实文件哈希和人工观察依据；这些边界进入提示词和缓存键。
- Dreamina CLI 是正式媒体 Provider。连接器执行前读取当前 CLI 子命令帮助并核对模型、分辨率、比例、参考数量和时长。
- 小说推文默认显式使用 `seedance2.0fast`、`720p`。2.0 Fast 的单元上限按当前 CLI 能力校验为 15 秒、9 图、3 视频；Seedance 2.5 为 30 秒、30 图、10 视频。能力来自实际帮助证据，不猜测。
- 提交前先保存执行尝试；拿到 `submit_id` 后立即持久化。恢复只查询原任务。提交结果不明且没有可靠 ID 时进入 `state_unknown`，禁止盲目重提。
- 视频门禁从拟采用区间抽取多个真实时间点；对白音轨听检单独记录。检测器缺失、未观察或证据不足保持 `unknown`。
- 终选视频保存文件哈希、采用区间、区间首尾真实帧哈希、实际末态和人工观察依据。强承接使用采用区间的实际末态；替换上游素材只使真实依赖链失效。
- 导出 `production-package` ZIP，包含采用图片/视频原文件、采用区间、镜头顺序、对白与声音提示、参考职责、来源映射、版本清单、可读分镜 HTML 和机器清单。配音、字幕和最终剪辑在外部软件完成；旧 B6 装配器仅保留兼容和粗剪用途。

## 从反馈中持续改进

每条经验都保存来源反馈、内容锚点或视频时间点、目标版本、适用作品/类型/呈现方向、触发条件、建议做法、例外、规则版本、应用记录和验证结果。

- 明确纠正直接用于当前作品。
- “不好看”等模糊反馈先给出定位建议，补充具体原因前不生效。
- 选稿、拒绝和修改差异产生的推测偏好保持待确认；单纯采用一稿不代表认可全部细节。
- 推广到同类作品或全部作品必须由用户确认。短剧节奏经验不会自动用于电影；本作品的人物、物件和剧情事实不会被带入其他作品。
- 生成后记录有效、复发、误用或证据不足。误用或范围错误会自动降级为待确认；撤销后立即退出检索、审查、缓存依据和后续会话增量。
- `ExperiencePack-v1` 用于 A/B 本地经验文件库交换；项目保存采用时快照，离开经验库仍可复现历史任务。

## 会话、缓存与恢复

- A 创作、小说分析、独立审查，B 的各呈现方向、场次导演和审查使用各自稳定的 Codex CLI 会话。
- 同一职责续接原会话，局部修改只同步变化、删除项、上一输出绑定及适用经验。正式采用稿和结构化数据库优先于聊天历史。
- 审查会话读取来源、约束、候选和证据，不继承作者的隐藏推理。
- 缓存键包含来源指纹、模型配置、规则/经验版本、身份版本、实际参考文件、采用区间和连续依赖。
- 运行中依据变化时，返回结果保留为旧版本候选；不静默采用。媒体下载失败只重试下载，付费媒体不自动重试。
