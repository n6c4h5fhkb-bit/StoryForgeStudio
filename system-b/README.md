# SYSTEM B 2.0 · FrameLab 视听导演系统

System B 在 A 的采用剧本基础上完成二次影视化、关键拍法、正式分镜、资产连续性、图片/视频生成、真实媒体审查和制作包导出。电影、剧集和快节奏短剧分别保存，不覆盖 A 原稿或其他呈现分支。

## 启动

安装 Python 3.11+。Windows 双击 `start.bat`；macOS 运行 `start.command`；Linux 运行 `./start.sh`。首次启动会创建 `.venv` 并安装固定依赖。

浏览器默认打开 `http://127.0.0.1:8788`。数据保存在本目录的 `data/`。

```bash
python launcher.py --check
python launcher.py --port 8798
python launcher.py --data D:/Studio/system-b
python launcher.py --test
```

## 实际工作流

1. 导入 System A 的 SceneExport v4，或继续使用旧小说/剧本入口。
2. 选择电影、剧集或快节奏短剧，阅读完整拍摄版、来源映射和主要改动理由。
3. 采用前查看影响预览；不同呈现版和历史版本都保留。
4. 在开场、人物亮相、反转、高潮和复杂调度中选择有实际差异的拍法。普通场次自动采用独立复核后的推荐稿。
5. 系统从采用拍摄稿提取素材，再按分镜筛选真正入画的身份和状态。参考图必须说明“控制什么”“不继承什么”。
6. 每批生成前查看任务、真实参考、缓存、参数和预计费用；图片、视频均需查看后采用。
7. 视频终选保存真实文件、采用区间、区间首尾帧证据、实际末态和观察依据；强承接从采用区间末态继续。
8. 导出“独立制作包 ZIP”，在外部软件完成配音、字幕和最终剪辑。

## Dreamina / Seedance

`dreamina` 是正式媒体 Provider。小说推文默认显式使用 `seedance2.0fast / 720p`；每次执行先读取本机 CLI 当前帮助，核对模型、分辨率、画幅、参考数量和时长。提交前保存执行尝试，收到 `submit_id` 后立即持久化；恢复只查询原任务。提交状态不明且缺少可靠 ID 时停止，防止重复付费。

真实 Dreamina 任务属于付费外部动作，平台仍要求逐批费用确认。演示 Provider 只生成带标记的本地测试图和测试视频。

## 连续性与经验

事件状态区分开合、损坏、服装、伤势、位置、持有、包含、未知、隐藏、空与销毁。故事顺序和播放顺序分别记录；预演、倒叙与跳时必须声明。修改身份、素材文件、上游视频或采用区间时，只传播到真实依赖项。

“反馈与记忆”可绑定场次、镜头、选中文字或视频时间点。当前作品的明确纠正立即生效；推测偏好和跨作品推广需确认。有效、复发、误用与证据不足分别记录，经验可停用和撤销。

## 模型、会话与交付

本地 Codex CLI 的全局设置和角色设置都提供 `GPT-5.6 Sol · High` 快捷预设，并同时设置 600 秒等待上限和 96,000 字符任务资料上限；各呈现方向、场次导演和独立审查复用稳定会话，只同步变化和适用经验。也可使用模型 API。独立制作包包含采用媒体原文件、采用区间、镜头顺序、对白与声音提示、参考职责、来源映射、版本清单、可读 HTML 和机器清单。

旧 B6 声音/字幕装配器仍保留用于兼容和粗剪；当前主交付以制作包为准，配音、字幕与最终剪辑由外部软件完成。

详细配置见 [配置说明](docs/CONFIGURATION.md)，完整能力见 [A/B 2.0 完整版本](docs/COMPLETE_VERSION_2026_09_28.md)，交换协议见 [SceneExport v4](docs/SCENE_EXPORT_V4.md)，验证结果见 [测试报告](docs/TEST_REPORT.md)。

## 部署边界

这是单用户本地源码，不是公网多租户服务。保持默认 `127.0.0.1` 监听。真实文字质量、人物表演和视频画质需要在你的模型账号上小范围试跑，离线测试不会伪装成付费模型效果。
