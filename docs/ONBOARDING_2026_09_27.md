# 启动流程更新 · 2026-09-27

## System A：AI 先给选题

“新建项目”直接进入选题工作台，第一次会准备四个选题。无需填写标题、种子、类型或秒数。选题卡展示故事梗概、开场钩子、核心两难和追看理由，人物与制作考虑可展开阅读。

- 可以选择“原创 · 人物与故事质量”或“短剧 · 强开场与追看欲”；补充偏好可留空。
- “换一批”产生新的请求；“沿这个方向脑暴”携带选中的完整构思继续探索。
- “用这个开始”用选题标题与内容建立项目，进入原有阅读、选择、展开流程。
- 批次持久保存，刷新或重新打开不会重复生成；进行中的任务可以恢复查看。失败不会伪装成真实 AI 选题。
- 重复提交同一次脑暴复用任务；重复采用同一选题打开同一个项目，不重复建项目。
- 选题使用 `ideation` 模型分工，未配置时继承故事结构模型，再继承默认模型。单批一次语言模型调用，不调用图片或视频服务。脑暴费用可以在选题工作台查看。
- 离线模式明确显示流程样例。真实模型需要在服务设置连接，不能用演示样例证明创作质量。

相关入口：`GET/POST /api/brainstorms`、`POST /api/brainstorms/{batchId}/ideas/{ideaId}/adopt`。

## System B：先内容，后时长

创建项目时选择画幅：16:9、9:16、1:1 或 2.39:1。风格和画幅是独立字段；之后套用其他风格档也保留已选画幅。“风格与人物”页提供直接修改画幅的按钮。已有设计修改画幅时，原有依赖影响预览继续生效。

创建表单取消全片目标秒数与媒体预算上限。后台也不再为新项目填入隐藏的固定总时长：

1. B0 理解原稿并拆分场次，此时场次时长为待定。
2. B1 在改编呈现中，根据对白、动作和情绪停顿提出每场时长及理由，用户采纳后保存。
3. B3/B4 采用已确认的场次时长规划调度、镜头和动作。新项目镜头数量随内容调整，风格镜数区间是建议；旧项目明确设置的时长仍可读取。
4. 全片预计时长由场次方案累加。成片阶段没有显式总时长目标时，不再拿一个默认秒数报警。

取消项目累计费用拦截与媒体执行任务的金额硬上限；旧项目的 `budget` 和旧设置中的预算不再限制调用。模型、媒体费用、缓存命中、在途费用仍记录，单次生成的费用预览、供应商单价配置、超时、并发和取消功能保留。

阅读工作台和 HTML 分镜导出按照选中的画幅展示画面。
