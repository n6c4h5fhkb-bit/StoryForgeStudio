# 剧本写法（script.md）

剧本是一集的唯一事实来源：谁在哪、做了什么、说了什么、什么东西变了。分镜和提示词都从这里来，所以剧本要短、具体、可演。

## 格式

```markdown
# EP01 倒计时

## 场1 医院大厅 · 日 · 第1天
【画面】林川抱着一摞病历冲进大厅，白大褂下摆被风掀起。 ^L001
主任：（冷笑）实习生也敢迟到？明天不用来了。 ^L002
林川（心声）：他头顶的数字……在往下跳。 ^L003
【音效】大厅广播的提示音
【状态】林川 放下 病历：导诊台
【时间跳转】十分钟后
护士（画外）：林医生，三号电梯！ ^L004
旁白：那天，他第一次看见死亡的倒计时。 ^L005
```

| 行 | 写法 | 说明 |
|---|---|---|
| 场次标题 | `## 场1 地点 · 时间 · 第1天` | 地点和 bible.md 的场景名一致；时间写 日 / 夜 / 晨 / 黄昏 等；「第N天」决定造型延续 |
| 画面 | `【画面】……` | 看得见的动作和结果，一行一件事 |
| 台词 | `人物：台词` | 语气写在台词前的括号里：`主任：（冷笑）……` |
| 心声 | `人物（心声）：……` | 不动嘴的内心话 |
| 画外声 | `人物（画外）：……` / `（电话）` | 人不在画面里，只听见声音 |
| 旁白 | `旁白：……` | 系列设定里旁白为「无」时，旁白不进视频提示词，留给后期 |
| 音效 | `【音效】……` | 有戏剧作用的声音 |
| 状态 | `【状态】……` | 会延续到后面的变化，见下文 |
| 时间跳转 | `【时间跳转】……` | 场内的时间省略；工具会在这里切开生成请求 |
| 备注 | `【备注】……` | 写给自己看的，不进提示词 |

行尾的 `^L001` 是行号，`sf ids`、`sf check`、`sf plan` 会自动补。改稿时保留已有行号，分镜靠它对应台词。

## 对白：从意图出发，不搬原文

原文是事实和人物依据，不是台词稿。每段关键交流先想清：这个人此刻想要什么、知道什么、必须说出哪条信息，再写他此刻会说的话。

- 口语短句。一句尽量不超过 25 个字；长段拆成你来我往。
- 人物要真的接对方的话，而不是各说各的。
- 能用动作表达的就别说出来：「她把钥匙放回桌上」胜过「我不要了」。
- 解释性台词压到最少，让观众从行为里看懂。
- 每句台词按每秒约 5 个字估时，短剧的节奏通常比小说对话快得多。

## 【状态】：只写会延续的变化

工具用【状态】行维护连续性：谁拿着什么、穿什么、哪里受了伤。写在发生变化的那一行后面，一行一件事：

```markdown
【状态】李树 拿起 铁棍：右手
【状态】李树 把 铁棍 交给 刘军
【状态】刘军 放下 铁棍：桌上
【状态】铁棍 放在：门后
【状态】林川 换上 便服
【状态】李树 受伤：左额角（贴着纱布）
【状态】刘军 受伤：右腿，跛行（昨夜，画外）
【状态】李树 痊愈：左额角
【状态】木箱 打开
【状态】U盘 消失
```

| 动词 | 意思 |
|---|---|
| 拿起、接过、掏出、夺下… | 道具到某人手里（冒号后可写哪只手） |
| 交给、递给 | 道具换人 |
| 放下、放在 | 道具离手，冒号后写放在哪 |
| 收起、藏起 | 道具在身上但看不见 |
| 戴上、背上 / 摘下 | 佩戴类道具 |
| 换上、换成 | 换造型，名字要和 bible.md 里的「造型（名字）」一致 |
| 受伤、包扎 / 痊愈 | 身体状况，冒号后写部位，括号里写看得见的样子 |
| 打开、关上、毁坏、消失、出现 | 道具本身的变化 |
| 昏迷、醒来、死亡 | 人物状况 |

不需要写的：站位、姿势、表情、视线、走到哪里。这些属于画面，写在【画面】行或分镜的动作里，下一镜不会自动继承。

括号里带「画外」表示变化发生在镜头外（例如前一晚受的伤）。

## 检查清单

- 每场开头有完整的场次标题。
- 台词的说话人都在 bible.md 里（或者是旁白）。
- 道具易手、换装、受伤都写了【状态】；场景切换时，手里还拿着的东西要么继续写进画面，要么写一行「放下」。
- 估一下长度：台词字数除以 5 是说话的秒数，加上动作和反应，大致就是这一集的长度。工具会给出准确的估算。
