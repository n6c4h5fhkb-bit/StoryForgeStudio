# 选材、改编与分集大纲

目标：把一批章节变成一份每集都有钩子、兑现和卡点的大纲。大纲定了，后面的剧本和分镜才不会返工。

## 1. 先读完一批连续章节，再决定一集讲什么

不要读一章写一集。把这次要用的连续章节读完，列一张事件池：

| 章节 | 发生了什么（处境怎样改变） | 主线事件 | 有用的支线（具体作用） | 去向：保留 / 合并 / 延后 / 删除 |
|---|---|---|---|---|
| 第3章 | 主任当众要开除林川 | 林川被逼到绝境 | 护士偷偷帮他（之后的盟友） | 保留到 EP01 |

两层压缩：

1. **先删整条事件或支线。** 不推动目标、不制造代价、不埋后面要用的线，就删。关系戏、喜剧、伏笔有用就留，不按类别一刀切。
2. **再压缩留下来的事件。** 小说里一大段过程，能用一个画面、一个动作或一句话交代就不要拆成五镜。被省掉的等待或过程，要留一个看得出时间过去的线索。

## 2. 每集一句话

写清：**谁要做成什么，什么挡着他，做不成会失去什么。** 一集的所有场次都为这一句服务。说不出这句话，说明这一集还没有想清楚。

## 3. 按功能重组，不按章节比例缩短

- 先找和本集目标相连、张力最大的事件做入口，再往前补最少的原因，往后安排兑现。
- 可以调整先后、把多次遭遇合成一次集中冲突、把重复的人物功能并到一个人身上。改了之后，检查后面的人物关系、伏笔和状态还成立。
- 冷开场（先放后面的爆点）要让时间关系看得懂，回到正题时不要完整重播。
- 保留顺序：用户明确要保留的 → 人物目标和题材体验 → 新版本的因果和兑现 → 节奏和可拍性 → 原文细节。

## 4. 一集里的起伏：双峰

**建立压力 → 第一次有效反制 → 反制招来更难的局面 → 付出代价换来主要兑现 → 后果和下一个目标。**

第一峰要有看得见的结果（争到时间、戳破一层谎言、拿到东西）。低谷来自对手的应对或真实代价，不要凭空空降更大的反派。第二峰回答本集的问题，靠已经铺好的能力、证据和人物选择，不临时发明无敌身份。

| 题材 | 第一次释放 | 主要兑现 |
|---|---|---|
| 逆袭、权力攻防 | 戳破局部谎言，挡住一次欺压 | 关键证据成立，控制权改变 |
| 悬疑、生存、微恐 | 发现线索，躲过一次危险 | 用铺过的规则破局，同时暴露新代价 |
| 情感、家庭、救赎 | 一次帮助被接受，误会松动 | 在真实风险里做出守护的选择 |
| 异能、系统、修炼 | 能力第一次奏效 | 能力经受考验，改变资源或处境 |

爽点不只是打脸。救下一个人、兑现一个承诺、被看见，也是释放。

## 5. 可选的商业机制（选能加强本集因果线的，不必集齐）

| 机制 | 怎么用 | 成立条件 |
|---|---|---|
| 倒计时、即时压力 | 眼前必须选，否则失去具体的东西 | 期限有来源，不能随意重置 |
| 信息差 | 观众知道主角不知道的，或和主角一起发现异常 | 分清观众、主角、对手各知道什么 |
| 道具回收 | 同一件东西先压迫人，后来变成证据或反击 | 用途或控制权真的改变 |
| 见证者反应 | 曾经误判的人看清事实、改变站位 | 拍他的行动改变，不是轮流震惊 |
| 结尾状态变化 | 新的威胁进门、关系改变、资格失去 | 本集已经有局部兑现，下一集继承这个变化 |

## 6. 时长参考轴（起点，不是公式）

**横屏剧集，约 240 秒：**

| 时间 | 功能 | 观众应该看到 |
|---|---|---|
| 0–15 秒 | 冷开场，目标入口 | 和核心冲突相关的动作、异常或强选择 |
| 15–60 秒 | 压力和代价 | 条件收紧，人物必须行动 |
| 60–90 秒 | 第一峰 | 一次反制或进展真的奏效 |
| 90–135 秒 | 升级 | 对手应对，或暴露更难的代价 |
| 135–195 秒 | 第二峰 | 关键能力或证据加上人物选择，回答本集问题 |
| 195–225 秒 | 后果 | 赢得或失去的东西具体可见 |
| 225–240 秒 | 卡点 | 新任务或威胁，让人想点下一集 |

**竖屏短剧，约 90 秒：** 0–3 秒钩子，3–30 秒冲突升级，30–60 秒反转或爽点，60–90 秒兑现加卡点。

工具按格式检查：钩子是否在开头几秒、第一个冲突是否够早、两个戏剧节点之间是否空太久、结尾有没有卡点（见 directing.md 的标记）。

## 7. 场景和人物怎么合并

- 优先一个主要冲突空间，必要时加短的辅助场景。空间转换要承担追逃、取证或危险升级。
- 合并重复的戏剧功能，不只按好坏裁人。施压者、保护对象、见证者是功能，可以由同一个人在不同阶段承担。
- 把心理和抽象地位外化成看得见的行为、证据或物件：资格被取消，就拍门禁刷不开。

## 8. outline.md 写法

```markdown
## EP01 倒计时
- 原文：第1–3章
- 一句话：林川要在十分钟内救下董事长，否则他会背上害死人的罪名被开除
- 钩子：林川看见董事长头顶的红色倒计时只剩 09:58
- 推进：主任当众拦他；护士偷偷递来急救包；保镖把他按在地上
- 爽点：林川挣开保镖，按住董事长的颈动脉，倒计时停住
- 卡点：董事长醒来后第一句话是叫出林川早已去世的父亲的名字
- 时长：约 240 秒
```

写完大纲先给用户看，这是整部剧最值得用户花时间的一步。用户说“直接做完”时，记下你的取舍理由，继续往下做。
