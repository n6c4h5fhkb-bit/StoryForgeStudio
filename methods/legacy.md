# 转换旧版（1.2.x）项目

旧版把每一镜的完整状态、逐行删改记录和审查记录都写进 board.json。新版只需要剧本、分镜和人物表，其余由工具推导。转换一次即可。

```bash
python <skill>/scripts/sf.py import-legacy <旧 board.json> <新项目目录> [--episode EP04] [--keep-durations]
python <skill>/scripts/sf.py plan <新项目目录>
```

一个系列有多集时，每集的 board.json 转进同一个项目目录，用 `--episode` 指定集号（标题里有「EP04」时会自动识别）。series.md、bible.md、outline.md 只在第一次创建；后面几集新增的人物要手动补进 bible.md。

## 会保留什么

- 人物、场景、道具，以及它们的外观描述。
- 每一场、每一镜：画面、台词、景别、角度、运镜、站位（写进 `舞台=`）。
- 道具易手、换装、受伤、开合，转成【状态】行。
- 旧版的戏剧节点（施压、反制、兑现、开场、结尾），转成分镜标记。

## 会丢掉什么

- 逐行删改记录、完整状态快照、旧的生成单元和分组说明、审查与批准记录。
- 站位、姿势这类表演状态。新版把它们写在画面里，不进连续性账本。
- 每镜时长：默认按台词和动作重新估算。旧版的台词时间多是占位，按自然语速算，整集通常会变短。想保留旧剪辑时加 `--keep-durations`。

## 转换后检查五件事

1. **报告里的整集时长。** 变短很多，说明旧稿的台词时间偏松；要补足时长，就补内容，不要拉长镜头。
2. **bible.md 的造型名。** 造型名来自旧的服装状态值，太长或太像描述的要改短，并同步剧本里的「换上」。
3. **剧本里的【状态】行。** 删掉明显多余的，补上漏掉的「放下」（报告里的 HELD_CARRYOVER 会提示）。
4. **【备注】行。** 旧版的时间说明和空间说明放在这里，不会进提示词。有用的站位信息搬到 shots.md 的「默认：轴线=」。
5. **提示词检查。** 报告里出现 PROMPT_META 或 PROMPT_ASCII，说明旧文本里还有写给作者的话或英文代码，到剧本或人物表里改掉。
